# 🧪 Pharmaceutical Sales Data Analysis (EDA Project)

## 📌 Project Overview

This project analyzes pharmaceutical sales data using Python, Pandas, and Matplotlib. The goal is to explore historical sales trends, identify top-performing drug categories, and uncover seasonal patterns.

---

## 🔗 Dataset Source

Download the dataset from Kaggle:
https://www.kaggle.com/datasets/milanzdravkovic/pharma-sales-data

After downloading, place the file in the following folder structure:

```
project-folder/
│
├── data/
│   └── salesdaily.csv
│
├── notebook.ipynb
└── README.md
```

---

## ⚙️ Tools & Technologies

* Python
* Pandas
* Matplotlib
* Jupyter Notebook (via VS Code)

## 🚀 How to Run This Project (VS Code)

### 1. Install Requirements

Make sure you have Python installed (preferably Python 3.8+)

Install required libraries:

```
pip install pandas matplotlib notebook
```

---

### 2. Open Project in VS Code

* Open VS Code
* Click **File → Open Folder**
* Select your project folder

---

### 3. Set Up Jupyter Notebook

* Install the **Jupyter Extension** in VS Code
* Open `notebook.ipynb`

---

### 4. Run the Notebook

* Click **"Select Kernel"** (top right)
* Choose your Python environment
* Run cells one by one using:

  * ▶️ button OR
  * `Shift + Enter`

---

## 🧹 Project Workflow

### 1. Data Loading

* Import dataset using Pandas

### 2. Data Cleaning

* Convert date column
* Handle missing values

### 3. Exploratory Data Analysis (EDA)

* Total sales by drug category
* Yearly and monthly trends
* Correlation analysis

### 4. Business Questions Answered

* Total sales per drug category
* Top-selling drugs
* Top 3 drugs in selected months
* Best-performing drug in 2017
* Average daily sales per category
* Seasonality of respiratory drugs (R03)

---

## 📊 Key Insights (Example)

* Certain drug categories consistently dominate total sales
* Respiratory drugs show seasonal demand patterns
* Some drugs have stable daily demand across years
